# Version 4 foundation — scientific and operational decisions

Baseline: 32949d3. This increment corrects historical price screening, exact-month anomaly comparisons, catalogue cache freshness, conflict handling, and explicitly separates older bilateral trade years. Current price eligibility is an unvalidated two-calendar-month recency rule; thresholds are screening prompts, not calibrated alerts.

The release generates a compact commodity index, per-product detail payloads, coverage counts, current market-signal register and national WDI context. The legacy full commodity file remains for backward compatibility and rollback. Client verifies all release files used against manifest and reuses in-session promises; detail files are loaded only for selected products or explicit compound scenarios. The compact index is not a full country profile. Old release support is retained. Browser map quantiles are relative, not cross-product risk thresholds; chart gaps use actual calendar periods.

Optional adapters use official FAO nominal food-price CSV, USDA PSD bulk download and GEOGLAM dated ArcGIS service catalogue. Optional source failure is shown as unavailable and cannot create a false zero or block core release. USDA output retains marketing year, provider geographic name, vintage fields and reported units; no stocks-to-use ratio from mismatched FAO denominators. GEOGLAM metadata is discoverable, not crop-condition value ingestion. FAO index is not domestic inflation; recent meat values may be revised. WDI context (water stress, irrigation, undernourishment, electricity, rural electricity, fertilizer application) is structural and not current drought or cold-chain capacity.

Situation Room, Watch, Briefs and Methods share country/product filters. Watch provides observed price screening and explicit unmonitored stages. Decision cards identify actors, constraints and checks; no prescriptive action or invented deadline. Stress Test caps hypothetical replacement by capacity and lead time; independent product losses are not added. Country comparisons show per-product values and dates, not arbitrary risk rankings.

Remaining release gates: verify actual optional source response schemas and licence/attribution, product coverage, CI, browser and accessibility. GIEWS/HDX domestic prices, WOAH disease, PortWatch logistics, CHIRPS/Copernicus crop-area hazards, AMIS event ingestion, observed trade-flow maps, constrained substitution with competition, historical vintage backtesting, and country-specific cold-chain data are still required. No event forecast, automated policy prescription, or validated causal network is claimed. Maintain historical data branch commits for reproducibility; a dedicated vintage archive and outcome registry remain future work.
